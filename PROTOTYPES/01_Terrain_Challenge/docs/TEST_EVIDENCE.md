# Deterministic and browser test evidence

Test date: 2026-08-30 (Europe/London)
Runtime: Node.js 22.19.0; Codex in-app Chromium browser; localhost only.

## Automated result

`npm test`: **7 passed, 0 failed**.

Covered assertions:

1. Same seed/settings create byte-identical `Float32Array` terrain and serialised state.
2. Same seed/settings create identical ENTRY and EXIT anchors.
3. Every preset places both anchors outside the obstacle and on supportable pads.
4. The straight route crosses a non-supportable obstacle centre.
5. Height queries agree with sampled rendered height-field vertices within `1e-5`.
6. River state is deterministic and uses the V3 rail transport mode.
7. `FLAT_GAP_SMALL` is flat, repeatable, and has the requested exact gap depth.

`npm run check`: **passed** for `src/terrain.js`, `src/app.js`, and `tools/serve.mjs`.
