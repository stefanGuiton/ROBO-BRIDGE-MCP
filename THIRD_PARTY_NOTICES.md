## Universal Robots kinematic reference

The UR10-class kinematic definition uses published Universal Robots DH dimensions as numeric reference data. The project includes no Universal Robots arm mesh, logo, firmware, or proprietary control software. The browser arm visual remains project-owned procedural geometry.

## WebMCP

The project calls the experimental browser `document.modelContext` API when it is available. No WebMCP browser implementation source is copied into this repository.

## Removed runtime dependencies

NVIDIA Newton, NVIDIA Warp, MuJoCo Warp, and the old Three.js SCARA runtime are not part of this release.
