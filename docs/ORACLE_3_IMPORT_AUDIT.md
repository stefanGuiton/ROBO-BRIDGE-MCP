## Decision

**Integrated with adaptation.** Oracle 3 supplied a simulator-native perception layer, bounded primitive WebMCP handlers, agent activity state, a deterministic fixture, a debug page, and qualification scripts. The package was a sparse runnable snapshot rather than a normal clone. Its production bridge was intentionally unavailable in the supplied snapshot, so the useful contracts were connected to the existing Oracle 1 UR10 `RobotController` and `BoardAdapter` through `apps/web/src/logo/runtime.js`.

The existing SCARA WebGL/WebMCP path was preserved. The Oracle 3 registration module was added as `register-oracle3-tools.js`; `apps/web/src/webmcp/register-tools.js` was not overwritten.
